# Style Profile — Pandu Sukma Hastyadi (Competition Essay Collection)

## How to use this file

Load this file before drafting any competition essay (KTI, scientific essay, opinion essay, international student competition, lomba esai). Apply every rule below unless a specific competition guidebook overrides it. Rules are derived from 3 competition essays (AURA, VIRLY, GUARD); a 4th source (KA-003 full research paper) was excluded — do not import its Methods/Results/Vancouver-citation conventions into essay drafts. Default English unless guidebook is Indonesian; Indonesian rhetorical patterns inside this file are preserved verbatim and may be used directly when drafting in Bahasa Indonesia.

## 1. Structural Rules

- **Open with national-scope problem statement.** Construction: "[Country/scope] faces [problem]" or "[Domain] requires [X]." Within 2 sentences, deliver an absolute-number statistic citing an official Indonesian or international body (BPS, Kemendikbud, OECD, SIPSN, World Bank, EDGAR, ministry regulation). Do not open with: dictionary definitions, generic quotes, anecdotes, rhetorical questions, first-person, or scene-setting fiction.
- **Use funnel arc:** national problem → specific Indonesian case site → traditional-method limitation → proposed tech solution → characterization/feasibility evidence → techno-economic projection → implementation roadmap. Apply this arc even when guidebook does not require it.
- **Always anchor to a real Indonesian case site** (e.g., Krueng Daroy River Aceh, Sungai Ciliwung Jakarta, rural ASEAN schools). Never write a problem-solution essay in pure abstract.
- **Close with numbered conclusions, 1:1 mapped to numbered objectives in §1.2.** If essay has 4 objectives, conclusion must have 4 points in same order. Each conclusion lead-verb: "successfully [proposed/demonstrated/validated/established]". This is grounded projection-claim about the invention, not overclaim — keep it.
- **Add `Saran`/`Suggestion` block** after conclusion: future research, project implementation, software development, teacher/stakeholder integration. Bulleted, action-imperative.
- **Default chapter structure:** BAB 1 PENDAHULUAN (1.1 Latar Belakang / Background, 1.2 Tujuan / Purpose) → BAB 2 ISI / BODY → BAB 3 PENUTUP / CONCLUSION (3.1 Kesimpulan, 3.2 Saran). Match competition's exact heading format if specified.

## 2. Sentence Rhythm Rules

- **Average sentence length: 25–35 words.** Long analytical sentences dominate. Do not chase brevity.
- **Ratio of short (<10 words) to long (>25 words): under 15% short.** Short sentences only for hard transitions ("This is a major issue.") or conclusion bullets.
- **Zero sentence fragments.** Zero one-word emphasis. Every sentence has subject + finite verb.
- **Compound-complex preferred.** Use semicolons sparingly; prefer clause chaining with "which", "where", "while", "however", "thereby", "consequently".
- **No staccato.** No two short sentences in a row outside conclusion lists.

## 3. Vocabulary Rules

- **Register: formal academic, accessible-expert.** Reader assumed = competition judge with science/engineering literacy but not necessarily peer in the subfield.
- **Define every acronym on first use.** Pattern: "Full Name (ACRONYM)" or "ACRONYM (Full Name)". Re-use acronym thereafter. This includes household ones if they're load-bearing (IoT, AI, PET, KOH, BET-SAA).
- **Technical jargon density: high.** Do not soften; competition judges reward precision.
- **Recurring lexicon to favor (English):** "highly", "significantly", "effectively", "potential", "integrated", "sustainable", "real-time", "feasible", "comprehensive", "optimized", "enhanced", "characterization", "implementation".
- **Recurring lexicon to favor (Indonesian):** "dirancang", "terintegrasi", "berkelanjutan", "real-time", "potensial", "efektif", "secara", "berbasis", "menjadi solusi", "menghadirkan".
- **Indonesian connective patterns to preserve verbatim when drafting in Bahasa:** "Hal ini...", "Selain itu,", "Berdasarkan...", "Dengan demikian,", "Untuk mengatasi permasalahan tersebut,", "Sejalan dengan...", "Di samping itu,".
- **Banned vocabulary:** "I", "we", "our team", "you", "imagine", "let's", "amazing", "incredible", "game-changing", contractions, em-dashes for drama, exclamation marks.

## 4. Argument Move Rules

- **Evidence introduction template (English):** "Data [body] [year] [verb: shows/reveals/indicates] [statistic] (Author, year)." OR "[Author] et al. (year) [verb: showed/demonstrated/reported] that [finding]." Use 5+ different lead-verbs across an essay (showed, demonstrated, revealed, reported, indicated, confirmed, achieved).
- **Evidence introduction template (Indonesian):** "Data [lembaga] [tahun] menunjukkan [statistik] ([Penulis], tahun)." OR "Menurut [Penulis] (tahun), [temuan]."
- **Counterargument handling: dismissal-pivot.** This is the user's signature move — keep it. Pattern: "While [traditional method] [does X well], [it has limitation Y], [making it Z]. This creates a critical need for [proposed solution]." Do NOT steelman opposing approaches; acknowledge briefly then pivot to invention.
- **Numeric density: target ≥1 statistic per paragraph in Background section.** Every number gets a citation.
- **Always quantify the invention's improvement** as percentage delta vs baseline ("87.35% higher than", "increase of 14.37% compared to", "reduction of 65% compared to commercial X").
- **Section transition phrases (verbatim, English):** "To overcome this issue,", "To optimize [X],", "Furthermore,", "In addition,", "This situation requires", "Specifically for the application at", "Based on [data/figure],".
- **Section transition phrases (verbatim, Indonesian):** "Untuk mengatasi permasalahan tersebut,", "Untuk memperoleh [X],", "Selain itu,", "Sejalan dengan tren ini,", "Berdasarkan konfigurasi...", "Dalam alur kerja...".

## 5. Voice Marker Rules

- **First-person: NONE.** Zero "I", "we", "our". Use passive voice or third-person nominalizations ("This study aims to...", "The system is designed to...", "Penelitian ini bertujuan untuk...").
- **Rhetorical questions: NONE.** Do not use them to open paragraphs or build drama.
- **Analogies and metaphors: minimal to none.** Stay literal. Describe mechanisms, not similes. Exception: one mechanism-clarifying analogy is permitted in BAB 2 if a complex technical process needs lay framing.
- **Tone: confident, neutral, projection-grounded.** Claims of success ("successfully demonstrates") are anchored to the proposed invention's projected behavior, not empirical hype.

## 6. Formatting Rules

- **Headings:** Bold, ALL-CAPS for chapter level ("CHAPTER 1 INTRODUCTION" / "BAB 1 PENDAHULUAN"), bold Title Case with decimal numbering for subsections ("1.1 Background of the Study" / "1.1 Latar Belakang").
- **Average paragraph length: 5–10 sentences (~150–250 words).** Do not write one-sentence paragraphs.
- **Figure/table reference is mandatory and inline.** Pattern: "[X] can be seen in Figure [N]." or "[X] is presented in Table [N]." Place this sentence at the end of the paragraph that introduces the visual. Use this construction every time a visual appears — do not vary for style.
- **Numbered objectives and conclusions** as decimal-numbered lists (1., 2., 3., 4.). 3–4 items typical.
- **Lists otherwise: avoid.** Prefer prose paragraphs over bullets in BAB 2 body. Bullets allowed only in §1.2 Purpose, §3.1 Kesimpulan, §3.2 Saran, and component/cost tables.
- **Bold for emphasis only on conclusion key phrases** ("Virly has been **successfully proposed**"). No italics for emphasis. Italics only for Latin scientific names (*Escherichia coli*, *staphylococcus aureus*) and foreign-language inserts.

## 7. Citation Rules

- **Default style: APA inline parenthetical** — "(Author, year)" or "(Author et al., year)". For Indonesian authors: "(Penulis dkk., tahun)".
- **Do NOT use Vancouver/numbered [1] citations** in essay format. (KA-003 used numbered style; that essay was excluded because it was a full research paper, not a competition essay. Stay APA for essays.)
- **Indonesian-to-international source ratio: target 50/50.** Always include both. Cite ministry regulations and BPS/SIPSN/Kemenlh data alongside Elsevier/Wiley/MDPI international papers.
- **Data-point density: ≥6 cited statistics per 1,000 words** in Background sections; ≥3 per 1,000 words in Body.
- **Bibliography section title:** "BIBLIOGRAPHY" (English) or "DAFTAR PUSTAKA" (Indonesian). Hanging-indent APA format with italicized journal/book titles.
- **Government regulations cited in full:** "Peraturan Pemerintah Republik Indonesia Nomor 22 Tahun 2021 tentang...".

Produksi sampah plastik nasional dilaporkan mencapai 6,8 juta ton per tahun dengan peningkatan sebesar 5% setiap tahunnya (Aini dkk., 2023).*"
- **Closing signature — bold lead-verb on each conclusion bullet.** Pattern: "**[Invention] has been successfully [proposed/demonstrated/validated]** as [role] for [problem]." - **Recurring closing flourish:** Always re-state the named invention acronym in the conclusion. Always tie it back to the case site.
- **Signature naming move:** Always coin a 4–6 letter device acronym whose letters expand to a full descriptive phrase (AURA = AI-monitored, Upcycled material, Reactive agent, Adsorbent & Antibacterial; GUARD = Green Upcycled AI Recognition Device; VIRLY = Virtual Reality Chemistry Laboratory). Acronym in title, expansion in §1 Background.

## 9. Scientific Essay (KTI) Rules

- **Always propose a named device/system** with a 4–6 letter acronym.
- **Always integrate three tech layers when relevant:** core material/chemistry + IoT sensors + AI model. Solar panel power source is a frequent fourth layer. If guidebook permits, include all three; do not pick one.
- **Always include a techno-economic block** with at least: ROI, NPV (in IDR with full digit format like Rp 18.432.438.093), BEP (%), POT (years). Reference Peters/Klaus/Ronald methodology when computing.
- **Always include a phased implementation roadmap** (Pre-Pilot → Pilot/Construction → Infrastructure/Market). Each phase: dates, main activities, funding source.
- **Always include a components table in Appendix** (No / Component / Specification / Quantity / Price/Pcs / Total Price). IDR currency. Real product names (DS18B20, Raspberry Pi 5, DFRobot SEN0189, Epever Tracer, EcoFlow Flexible 100W).
- **Data presentation: narrative-framed, not pure-data drops.** Numbers always come with context: source, comparison baseline, why it matters. Pattern: "[Statistic from authoritative source]. [What it exceeds/falls below]. [Health/economic/regulatory consequence]."
- **Methodology framing:** Embed in flowing prose, not bullet steps, except in dedicated Methods sections (only when guidebook requests). Cite synthesis-protocol sources for every step.
- **Reader assumption:** Educated general / policy-maker / judge with technical literacy but not subfield expertise. Define jargon. Provide mechanism-level explanation when terms first appear (e.g., explain "fluorescence quenching", "BET surface area", "DCFRR" on first use).
- **Figure-and-table references woven in prose:** Always use the inline construction (see §6).
- **Indonesian academic source framing:** Indonesian sources cited equally to international ones. Frame Indonesian sources as authoritative for local context (BPS for population/waste data, ministry regulations for legal thresholds, regional government data for site-specific contamination); frame international sources as authoritative for synthesis methods, mechanism evidence, and benchmark comparisons.
